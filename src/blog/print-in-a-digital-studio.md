It would be easy to let print work quietly disappear from the studio's roster. Most new inquiries are for web products, apps, or digital campaigns. We keep taking print projects anyway, and it makes the digital work better.

## Constraints teach discipline

A four-color print run doesn't forgive a sloppy grid the way a browser does. Working within those constraints sharpens habits that carry over into every other medium we touch.

## Physical objects change client conversations

Handing someone a printed proof changes the conversation in a way a Figma link never quite does. It's worth protecting that.
